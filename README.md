# CCC Tracker

Offline-first commitment and daily check-in tracker with local backup and 24-hour lock rules.

## Use Cases

- **Daily Commitment Tracking:** Log daily commitments, targets, and completion status without needing an account or cloud sync.
- **24-Hour Lock Accountability:** Track remaining time until the daily lock window using the countdown badge.
- **Local Data & Backup:** Keep data locally in the browser/device and export or restore JSON backups (`ccc-auto-backup.json` or manual JSON backup).
- **Light & Dark Theme Support:** Switch between light and dark modes while viewing today's date and timezone (`DD Month YYYY TZ`).

## How to Use

1. Open the app (`index.html` / hosted web build or Capacitor mobile build).
2. Create a commitment with frequency, target, and threshold settings.
3. Log progress daily and monitor the countdown before the lock resets.
4. Export/import JSON backups whenever moving devices or saving snapshots.
